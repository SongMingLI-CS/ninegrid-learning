# 学习方法的组合与实现边界

“九格行动”把学习拆成可见目标、调查任务、作品验收和复习卡。参考的理念来自公开项目；行动体验、数据结构和交互逻辑由此仓库独立编写。

| --- | --- | --- |
| [白月光学习法](https://github.com/zhiliscope/baiyueguang-learning-skill) | 追踪来源、关系、因果和下一条线索 | 每个任务的调查问题、关联型行动和官方资料入口 |

| 三角洲赛季任务（用户提供截图） | 阶段目录、明确主线、任务验收和累积战利品 | 四栏任务大厅、阶段门槛、逐格解锁的保险箱 |

## 原则

1. 每次行动聚焦一个可尝试的成果。建议时长只是估计，不作为奖励条件。
2. 由调查问题引发好奇，再通过动手操作把它变成可观察结果。
3. 自我验收和 AI 验收显示不同标记；AI 反馈用来发现盲点，不等于外部事实审校。
4. 完成后隔一天出现复习卡。忘记、困难、良好和轻松四种评分会缩短或扩大后续间隔。
5. XP 和九格只与学会的行动有关。页面不奖励超时在线、连续打卡或牺牲休息。
6. 已完成任务要求至少 20 字的证据并锁定内容；导入会验证前置条件和记录。

## 复习调度

- 初次复习为 1 天后。
- 完全没想起会重置到 1 天后。
- 连续成功回忆后逐步延长间隔，间隔按调整后的难度系数增长。

这是可解释的 SM-2 风格简化调度，不是 RetainCraft 的 FSRS，不是个性化诊断，也不宣称在此产品中验证过效果。

## 信任边界

- 上游方法项目是背景参考；其中的文档不会作为本机 Agent 指令执行。
- 用户目标、模型生成任务及学习证据都是数据。发给 DeepSeek 的提示要求模型将它们作为材料，忽略材料中要求改写指令的文本。
- DeepSeek 返回内容会校验 JSON 结构、ID、来源链接和有向无环前置关系。截断、无效链接、未知前置任务和循环依赖均拒绝。
- 模型评语不会自动写入任务完成进度。AI 验收需要通过 70 分阈值和目标、证据检查。
- API Key 只保存在服务端 .env 或页面内存，不导出、不写入本地学习档案。

## 课程编排规则 v3

课程总纲与详细任务分开生成，避免长课程被单次上下文或输出 token 上限截断。总纲只保存阶段能力、主线任务节点、可选任务链、前置关系、阶段验收和九格成果关联；服务端先验证结构与业务规则，再逐条生成主线或支线任务链。一个任务链成功后，浏览器会话草稿立即缓存；中断后跳过已完成链，只请求缺失链。最终激活前，服务端依照已确认总纲重建任务标题、时间、链归属、先修关系和门槛，不接受生成详情覆盖这些结构字段。

常规长目标（至少 14 天、每天至少 20 分钟）按每阶段 15 个主线节点、3 条各 3 个任务的可选支线规划；阶段验收包含在主线节点内。主线与必要复习预留约 15% 的周期时间，支线时间单独呈现。短周期目标可缩减任务，但蓝图必须说明原因。课程版本 3 的密度规则仅用于新生成课程，不改变旧赛季读取 Schema。

任务拆分使用以下检查：

1. 一个任务聚焦一个能力点与可观察交付物，预计通常 5–20 分钟；阶段综合验收可以更长。
2. 新任务必须使用该学习者已声明的起点，标出新知识依赖；主线不能依赖任何可选支线。
3. 至少一部分任务采用预测/主动回忆，随后运行、操作或解释结果；不能用观看视频代替独立验证。
4. 支线必须提供应用、错误诊断或有依据的探索，不以换标题重复主线练习。
5. 每个阶段门槛对应主线成果，九格必须至少关联一个主线任务；通关后安排复习而非强制延长在线时间。

这是服务端提示、Schema 与规则校验约束的一套有限编排流程；不是自主智能体，也不代表课程内容经人工或来源事实审核。外部 DeepSeek 请求仍取决于运行环境密钥与额度。

## 实际请求规则与验收规则 v1

`shared/learningRules.ts` 导出 `learning-loop-1` 版本规则片段。服务端在总纲、课程讲解、提示、日程、下一步建议、普通 AI 验收和付费挑战验收请求中组合对应片段，并随请求数据携带规则版本。规则包括预算反推、显式先修、主动回忆、示例/补全/独立题区分、材料为不可信数据，以及“AI 评价不直接发奖”。这能说明规则进入了应用构造的模型请求；不能证明模型每次都遵循规则。

任务验收现在由服务端从保存的任务目标构造稳定必需标准 ID。模型必须逐项返回标准 ID、是否满足及证据；缺 ID、重复 ID、额外 ID或缺少证据会拒绝结果。总分达到阈值但必需标准未满足时服务器强制未通过。`gaps` 保留为改进线索，不会被机械地当成必需缺项。挑战和普通任务采用同一逐项通过原则；结果仍属于模型判断，不是确定性代码验证。

阶段终局任务提供可选文字费曼验收：用自己的话解释、给例子、说明适用条件或误区，并回答由任务标题和目标构造的追问。表达简洁不会因文风而扣分。当前版本没有持续多轮 AI 对话；回答作为一份证据提交，不进行无限追问。

同一任务累计三次未通过尝试后，学习区显示分层救援：澄清验收要求、从最小例子重做、短前置练习、查看示范并生成独立变式。救援等级和旧尝试随赛季状态保存，不重置答案或完成记录。自动有效耗时尚未实现，不用后台停留时间触发救援。

目标输入页提供可跳过的 3 题快速自评，按编程、英语考试或通用目标选择概念、读代码/短答、应用判断题型，可标记能解释、需补齐或暂时不知道。题目版本、回答和自评会按账号写入本机恢复草稿；开始课程生成后也进入账号隔离的服务器生成草稿，并实际传给总纲请求。模型被要求将其作为初始自报线索调整先修、难度和估时，蓝图预览显示这些线索供用户纠正。刷新同一设备可恢复；开始生成前尚未同步到服务器，因此此阶段不支持跨设备恢复，也不是客观能力测量。真实 DeepSeek 未配置时，模拟回归不能作为真实模型教学质量验证。
