# NineGrid Implementation Plan

> For agentic workers: execute the scoped tasks in the current session and review their boundaries before integration.

**Goal:** Build a tactical learning campaign UI with DeepSeek generation and evidence-backed progression.

**Architecture:** React renders browser-local state. Shared schemas validate both persistence and AI output. Express proxies requests to a fixed DeepSeek endpoint with session-only or environment credentials.

**Tech Stack:** TypeScript, React 19, Vite 7, Express 5, Zod 4, Vitest 3.

**Spec:** docs/superpowers/specs/2026-10-13-ninegrid-design.md

## Global Constraints

- Do not persist or export API credentials.
- Preserve current campaign on generation failure.
- Imported data and AI output must pass shared validation.
- A task cannot award twice or bypass unmet dependencies.
- Local/demo checks and AI judgments must be distinguishable.
- Nine slots reflect progress; the project does not promise sustained 10-hour concentration.
