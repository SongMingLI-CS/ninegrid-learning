# 九格行动：多用户学习赛季与资源闭环

## 目标与边界

本改造在现有学习闭环、赛季进度、奖励去重和 localStorage 档案上扩展多用户服务端存档；阶段性保留无数据库的本地开发/演示方式。生产环境使用 PostgreSQL、账户会话、服务端 DeepSeek key 与私有附件目录。浏览器仅作缓存，奖励余额由服务端事务流水决定。绝不奖励挂机、熬夜或纯观看。

层级为赛季 → 阶段 → 主线/可选支线 → 任务链 → 任务。主线决定通关，支线推荐不阻塞。九格仅对应独立验收的关键能力/作品；钱包与道具仓库是用户级共享资产。任务、课程、复习和评价需绑定 owner、赛季、任务及内容版本。

## 正确性

- 复习详情、答案、评分、历史和下次排期使用显式同一 taskId；切换任务/赛季清空局部答案、提示、评分和识别状态。节目表复习完成状态看本次复习记录，不看原任务是否已通关。
- 补充证据变更保留原始自评证据，但使旧 AI 评价失效；AI 升级要求评价证据指纹等于当前完整证据指纹。
- “已掌握”是可保存诊断挑战：通过后记录为自评诊断完成，不产生 AI 标记或高价值奖励；失败展示可立即执行的补练任务。
- 目标勾选必须更新持久进度；任务切换重置任务局部状态。
- 课程/每日节目表/详细教学/评价分别按需生成并由 Zod 校验，按对象和内容版本缓存。旧记录不能被课程调整覆盖。

## 服务端架构

新增 Postgres migrations：users、sessions、seasons、wallets、inventory、reward_ledger、attachments。季节 JSON 状态设置 owner_user_id 和 revision，由服务端强制归属；奖励流水有 user_id、season_id、task_id、唯一幂等键，在事务中更新余额、库存与任务完成状态。附件私有落盘，不置于静态目录，读取时验证登录用户和赛季所有权。迁移 localStorage 必须先预览、确认，服务端校验并幂等写入且回传摘要，成功核对后客户端才可删除旧档。

采用 Argon2id 密码摘要、服务端 Postgres session、HttpOnly/SameSite=Lax Cookie、生产 Secure、CSRF token、自定义可信代理配置、注册/登录和 AI/上传限流、Helmet、JSON/body/file limits。生产必须要求数据库与 session secret。所有赛季、奖励、复习、附件、AI 路由验证所有权；使用参数化 SQL 和乐观 revision，冲突返回 409，不静默覆盖。

## 教学资源

YouTube Data API 搜索必须真实得到候选，随后用 videos.list 核验可用 ID、标题、频道、时长和缩略图。AI 仅解释候选与当前任务匹配度，不创造已核验事实。记录 source、checkedAt、match rationale，并明确“元数据核验≠看过/内容核验”。1–3 个候选、时间预算计入节目表；无服务或失败时给出明确未核验的 YouTube 搜索链接和关键词。缓存控制搜索配额。片段时间戳只有字幕/章节/可靠内容依据时显示。

教学图优先程序生成可访问 SVG/结构图；几何、数组维度和代码输出来自确定性数据。图片上传验证 MIME、魔数、解码、大小、尺寸，使用随机私有文件名。DeepSeek 视觉采用官方支持的多模态 image content block，经服务器调用；先展示 OCR/识别摘要供用户确认，再分析。图片证据不能单独证明独立掌握；视觉失败保留文本答案。附件不写入赛季 JSON、浏览器存储或日志。

## 体验与部署

总览严格沿参考图的左阶段轨道、中任务列表、右任务详情/奖励结构，显示锁定原因、完成/自评/AI 验证和主支线。工作区以约 16px 正文呈现讲解→例子→引导→独立挑战→反馈。奖励结算只读真实流水。移动端改顺序，不压缩正文。使用原创图形，不复制游戏美术。

Ubuntu 部署随仓库提供 Dockerfile、Compose、环境变量示例、数据库迁移/备份恢复说明和健康检查；只添加可审查部署文件，不连接或改写现有服务器。实际 DeepSeek/YouTube 调用必须由配置的真实凭据验证；否则报告未验证，不将 mock 标成真实成功。

## 验收

包含复习第二张到期卡不串题、证据变更失效/复核、诊断保存/失败补练、奖励幂等、多用户隔离和附件越权、迁移预览和重复迁移、视频无 API 降级/检索失效处理、图像真实 image block、视觉失败保留文本、预算及内容版本缓存的测试；最终验证完整 NumPy 流程、桌面 1366×768/1920×1080 与手机布局、重启后数据库数据。无法连接真实外部凭据的路径显式标记未验证。
